# Campus Market - Senior to Junior (Version 1)
Welcome to the first version of **Campus Market**, a lightweight, single-page web application designed for college students to buy and sell engineering tools and college equipment (like T-squares, lab coats, drawing boards, textbooks, etc.) safely and easily.
This version is designed as a **single-file project (`index.html`)** utilizing vanilla HTML, CSS, JavaScript, and Supabase for backend database and authentication.
---
## 🚀 Features
- **Single Page Application (SPA):** Seamless view switching via simple DOM manipulation.
- **Buyer Feed:** Browse all active listings sorted by upload date. Includes item names, descriptions, prices, and seller contact information (phone/WhatsApp).
- **Seller Authentication:** Integrated email-based registration and login system powered by Supabase Auth.
- **Seller Dashboard:** Sellers can view, manage, and delete their active listings once logged in.
- **Listing Tool:** A simple submission form for logged-in sellers to post new equipment listings.

## 🛠️ Supabase Configuration & Schema
To run this application with your own backend, you must configure a Supabase project.
### 1. Database Table
Create a table named `items` in your Supabase database using the following SQL schema:
```sql
create table public.items (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default now() not null,
  seller_email text not null,
  seller_name text not null,
  seller_phone text not null,
  item_name text not null,
  item_price numeric not null,
  item_desc text not null
);
2. Row Level Security (RLS) Policies
To ensure security, enable Row Level Security (RLS) on the items table and configure the following rules:

Read Access: Allow anyone (authenticated or anonymous) to view items:

sql


create policy "Allow public read access"
on public.items for select
using (true);
Insert Access: Allow authenticated users to add new items:

sql


create policy "Allow authenticated insert"
on public.items for insert
to authenticated
with check (auth.jwt() ->> 'email' = seller_email);
Delete Access: Allow authenticated sellers to delete only their own items:

sql


create policy "Allow individual delete access"
on public.items for delete
to authenticated
using (auth.jwt() ->> 'email' = seller_email);
💻 How to Run Locally
Clone or download this folder.
Update the credentials in index.html with your Supabase credentials:
javascript


const SUPABASE_URL = 'YOUR_SUPABASE_URL'; 
const SUPABASE_KEY = 'YOUR_SUPABASE_ANON_KEY';
Open index.html directly in your web browser, or serve it using a local development server such as:
VS Code Live Server extension.
Python's built-in server (run python -m http.server 8000 in the directory and go to http://localhost:8000).
Node.js serve package (run npx serve .).
